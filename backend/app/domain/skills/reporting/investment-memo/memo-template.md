# Memo template (markdown)

Ported from Dexter's `write-memo/memo-template.html` as markdown sections. Keep the order; fill every slot.

```
# {ticker} · {LONG|SHORT} · {horizon} · Conviction {high|medium|low}
Price {price} · Target {base target or "see scenarios"} · Asymmetry {upside/downside or "n/a"}

## Variant View
{max three sentences: what we see, why, why the market has not priced it}

## Thesis
- **{claim with number}** — {evidence with number}. *Wrong if {observable}.*
- (3-5 bullets)

## Business
{4-5 lines: what they sell, how they make money, segment mix, unit economics that matter}

## What's Priced In
{current multiple, implied growth/margin, consensus FY+1/FY+2 if available; where we differ and by how much}

## Scenarios
| | Bear | Base | Bull |
|---|---|---|---|
| Probability | | | |
| Revenue growth | | | |
| Margin | | | |
| Exit multiple | | | |
| Price target | | | |
| Return | | | |

**Bull:** {one coherent paragraph}
**Base:** {one coherent paragraph}
**Bear:** {steelmanned paragraph}

## Catalysts
| Event | When | Expected impact |
|---|---|---|

## Risks & Tripwires
| Risk | Mitigant | Tripwire |
|---|---|---|

## Position Management
- Sizing: {% of portfolio, tied to conviction × asymmetry}
- Entry: {price or condition}
- Stop / scale-out: {level or trigger}

## Monitoring KPIs
- {3-5 specific metrics that confirm or kill the thesis}
```
