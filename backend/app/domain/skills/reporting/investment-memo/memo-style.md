# Investment Memo Style Guide

Ported from Dexter's `write-memo/memo-style.md`.

## Voice
- First person plural ("we believe", "our base case").
- Direct, not hedging: "Margins compress 200bps in '27", not "margins could potentially face pressure".
- Confidence calibrated by evidence; hedge once with a "wrong if", not in every sentence.
- One idea per sentence in narrative sections.
- Thai answers follow the same rules in natural Thai; keep tickers and numbers as written.

## Banned vocabulary
"delve", "leverage" (as a verb), "robust", "comprehensive", "holistic", "seamless", "navigate the landscape", "in today's fast-paced", "stands out", "deep dive", "unpack", "moreover", "furthermore", "additionally", "It's worth noting that".

## Banned constructions
- Tricolons for rhythm ("fast, scalable, and reliable")
- More than one em dash per paragraph
- "Not just X but Y"
- Generic closing summaries ("In conclusion…")
- Hedge stacking ("could potentially possibly")

## Numbers
- Quantify everything: "margins expanded 380bps", not "improved meaningfully".
- Percentages with an explicit base: "revenue grew 28% YoY".
- Multiples in line: "trading at 18x FY26 EPS".
- Never invent numbers or consensus. If a number is not in a tool result, write "not disclosed" / "not available".
- Every number keeps its provenance marker from the data.

## Bear case
1. Steelmanned — written as if you believed it.
2. Name the competitor / customer / regulator.
3. A coherent world, not a list.
4. If the bear paragraph reads weaker than the bull, rewrite it.

## Tripwires
Each risk has an observable data point that would invalidate the thesis within the holding period ("Q3 gross margin below 40%"), never a vibe ("macro deteriorates").

## Ending
No conclusion section. End on Monitoring KPIs.
